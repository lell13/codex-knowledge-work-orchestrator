# Contributing

Thank you for helping make knowledge-work orchestration more useful and measurable.

## Good contributions

- Reproducible benchmark results from realistic knowledge-work tasks.
- New examples with clear inputs, acceptance criteria, and observed outcomes.
- Corrections to model profiles when official availability or guidance changes.
- Improvements that reduce unnecessary delegation, context, or latency.
- Artifact-specific verification rules supported by real failure cases.

## Before opening a pull request

1. Keep the change focused.
2. Run `python scripts/validate.py`.
3. Explain the user problem and observable improvement.
4. Include evidence for any efficiency or quality claim.
5. Avoid private, proprietary, or identifying source material in examples.

By participating, you agree to follow the [Code of Conduct](CODE_OF_CONDUCT.md).
