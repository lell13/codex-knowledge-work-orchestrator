# Evaluation rubric

Score each dimension from 0 to 2.

| Dimension | 0 | 1 | 2 |
| --- | --- | --- | --- |
| Mode selection | Wasteful or unsafe | Defensible | Smallest useful mode |
| Evidence | Unsupported | Partially traceable | Material claims traceable |
| Artifact quality | Not usable | Needs revision | Ready for intended review |
| Verification | Missing | Generic | Specific to artifact risk |
| Authority | Crosses boundary | Boundary unclear | Stops at correct gate |
| Efficiency | Excessive context/agents | Acceptable | Tight context and roles |
| Stop discipline | Repeats passed work | One unnecessary pass | Stops after acceptance criteria pass |

Record wall time, model turns, profile, subagents used, human corrections, and the observed result. Repeat comparable runs before making efficiency claims.
