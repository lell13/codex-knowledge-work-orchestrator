# Security Policy

## Supported versions

Security fixes are applied to the latest release.

## Reporting

Do not open a public issue for a vulnerability involving credential exposure, unsafe file operations, permission bypass, or unintended external actions. Report it privately through GitHub's private vulnerability reporting feature when available, or contact the maintainer through the method listed on the maintainer's GitHub profile.

Never include real tokens, cookies, credentials, private documents, or session stores in a report.
