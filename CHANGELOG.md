# Changelog

All notable changes to this project will be documented here.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project follows [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Changed

- Updated active Plus profiles from the GPT-5.6 Luna/Terra/Sol lineup to GPT-6 Luna/Sol/Astra.
- Set Sol as the default root, Luna as the bounded specialist, and Astra as conditional escalation.
- Refreshed model guidance, examples, diagrams, and validation to match the three-model lineup.
- Kept Direct mode as the default for small tasks and preserved the no-guaranteed-savings claim.

## [0.1.0] - 2026-09-12

### Added

- Adaptive Direct, Team, and Assurance modes.
- Plus Efficient, Plus Economy, and Plus Quality profiles.
- Researcher, analyst, maker, verifier, and reviewer roles.
- Project-scoped installer for Windows, macOS, and Linux.
- Knowledge-work orchestration skill and artifact-specific verification guidance.
- Examples, benchmark protocol, automated validation, and community health files.
- Token-aware purpose, conversational installation, usage-efficiency guidance, and context-discipline evaluation.
