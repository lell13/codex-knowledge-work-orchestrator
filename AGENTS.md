# Project instructions

This repository develops an adaptive Codex orchestration pattern for knowledge work.

- Keep documentation, examples, configuration, and public communication in English.
- Preserve the principle: use the smallest team that materially improves the result.
- Treat context, model escalation, and agent turns as a limited user budget.
- Prefer fewer handoffs and do not repeat passed checks without a concrete reason.
- Do not make Astra or reviewer invocation mandatory for routine work.
- Keep role behavior separate from profile model assignments.
- Treat external actions, publication, spending, permissions, and irreversible changes as approval-gated.
- Validate profile TOML, skill metadata, links, and examples before claiming completion.
- Do not edit benchmark claims without reproducible evidence.
