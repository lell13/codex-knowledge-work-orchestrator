# Delegation contract

Use this shape for a bounded assignment:

```text
Objective: [one concrete outcome]
Scope: [sources, files, section, or question]
Context: [minimum relevant background]
Constraints:
- [must preserve]
- [must not do]
Deliverable: [artifact or concise report]
Acceptance criteria:
- [observable check]
- [observable check]
```

For research, require source links and separation of fact from inference. For artifact production, name the exact file or section the agent owns. For verification, provide the artifact and acceptance criteria without telling the verifier what conclusion to reach.
