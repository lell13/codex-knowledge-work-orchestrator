# Operating modes

## Direct

Choose Direct when the task has one coherent output, little ambiguity, and no material need for independent evidence or review.

Examples: a short rewrite, a simple summary, a localized document correction, or a calculation with supplied inputs.

## Team

Choose Team when at least one bounded assignment can proceed independently and materially improve the result.

Useful patterns:

- Root studies internal context while a researcher gathers current external evidence.
- Researcher extracts sources while a maker builds a table from already-approved inputs.
- Verifier checks an existing artifact while the root prepares the executive narrative.

Team mode normally uses one or two subagents.

## Assurance

Choose Assurance when errors could materially affect a decision, publication, financial interpretation, privacy, or an action that is costly to reverse.

Add the smallest assurance mechanism that addresses the actual risk:

- factual risk: researcher or verifier
- calculation risk: verifier
- reasoning risk: analyst or independent reviewer
- artifact risk: format-specific verifier
- authority risk: explicit user approval before external action

Assurance does not mean spawning every role.
