# Code of Conduct

We want this project to be a practical, respectful place to compare workflows and improve them with evidence.

## Expected behavior

- Be respectful and specific.
- Critique ideas and results, not people.
- Disclose assumptions and conflicts of interest.
- Protect private and proprietary information.
- Prefer reproducible evidence over model fandom.

Harassment, discrimination, doxxing, threats, and deliberate disruption are not tolerated. Report conduct concerns privately to the maintainer through the contact method listed on the maintainer's GitHub profile. Reports will be reviewed promptly and handled with appropriate confidentiality.
